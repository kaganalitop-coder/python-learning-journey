## 🚀 Nasıl Kullanılır?

### Kurulum
```bash
# Repository'yi klonlayın
git clone https://github.com/kullaniciadi/python-learning-journey.git

# Dizine girin
cd python-learning-journey
```

### Çalıştırma
```bash
# Herhangi bir Python dosyasını çalıştırın
python3 01-basics/01_strings.py
python3 02-lists/01_list_basics.py

# Veya
python 01-basics/01_strings.py
```
